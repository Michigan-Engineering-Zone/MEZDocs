# Systemcore Fall 2026

## Systemcore

- There will be a new main robot computer in 2027
- It's called Systemcore and it will replace the Roborio
- Every team will get one in the kit of parts
  - You can purchase another if you'd like; ordering opens on December 3

## Systemcore Changes

- Some things will change
  - Wiring connectors
  - The dashboard/driver station
  - Several other details, presumably
- Some things look like big upgrades
  - More powerful, hopefully easier to get running
  - Has a built in IMU (gyroscope) sensor
